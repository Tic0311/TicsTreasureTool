# Changelog

All notable changes to Tic's Settler Toolkit are documented here.

## 1.0.0

Initial public release.

### Features

- In-game F8 toolkit with draggable and resizable UI.
- Settler health, energy, hunger, stress, level, experience, and skill-point editing.
- Generated attribute editing for Strength, Constitution, WillPower, Intelligence, Agility, and Perception.
- Main/Sub trait display and Add, Replace, Remove controls.
- Persistent learned trait catalog stored under BepInEx config.
- Scrollable carried-inventory editor for stackable entries.
- Settlement gold editing.
- Game-speed controls.
- Input blocking inside the toolkit while preserving normal game clicks outside the window.

### Compatibility

- Tested with Dungeon Settlers v0.4.19 Early Access.
- Tested with BepInEx 6.0.0-be.788 Unity IL2CPP Windows x64.
